GitHub 열쇠 — 아직 없음

버튼이 저장소의 작업(Actions)을 대신 눌러 주려면 GitHub 가 「이 사람이 주인」임을 알아야 합니다. 열쇠는 한 번만 넣으면 이 브라우저에 남고, GitHub 에만 보냅니다.

  1. GitHub → 오른쪽 위 내 사진 → Settings → 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. 이름은 아무거나(예: politics 버튼). Expiration 은 길게.
  3. Repository access → Only select repositories → politics-news
  4. Permissions → Repository permissions → Actions 를 Read and write 로. (Metadata 는 저절로 켜집니다)
  5. Generate 를 누르고 나온 github_pat_… 글자를 아래에 붙여 넣기
